Create a professional Task Management Web Application using HTML5, CSS3, and Vanilla JavaScript (no frameworks or libraries).

The purpose of this project is to demonstrate real-world frontend development skills suitable for a software developer resume and technical interviews.

Project Structure:
Provide three separate files:
1. index.html (use proper HTML5 semantic elements)
2. style.css (use modern CSS3 features)
3. script.js (use clean, modular JavaScript)

HTML5 Requirements:
- Use semantic elements such as:
  header
  main
  section
  form
  input
  textarea
  button
- Use proper labels and input types
- Use date input (HTML5 date picker)
- Ensure accessibility and clean structure

CSS3 Requirements:
- Use modern CSS3 styling
- Use Flexbox and/or Grid for layout
- Use responsive design with media queries
- Use hover effects and transitions
- Use card-based layout for tasks
- Use background image with overlay
- Use different colors for priority and status
- Ensure mobile-friendly design

JavaScript Functional Requirements:

Task Features (CRUD):
- Add new task with:
  - Title (required)
  - Description (optional)
  - Priority (High, Medium, Low)
  - Due date (required)
- Edit existing task
- Delete task
- Mark task as completed or pending

Filtering Features:
- Filter tasks by status:
  - All
  - Pending
  - Completed
- Filter tasks by priority:
  - All
  - High
  - Medium
  - Low

Local Storage:
- Save tasks using LocalStorage
- Load tasks automatically on page load
- Update storage when tasks are modified

Validation:
- Required field validation
- Due date cannot be in the past

JavaScript Concepts to Use:
- DOM manipulation
- Event listeners
- Functions
- Arrays and Objects
- Array methods (push, find, filter, map)
- LocalStorage
- Dynamic element creation

Code Quality:
- Use clear, human-friendly variable names
- Organize code into reusable functions
- Add comments explaining important logic
- Write code like a real frontend developer

UI Requirements:
- Professional and clean design
- Responsive layout
- Task cards with buttons
- Color indicators for priority and status
- Empty state message when no tasks exist

Goal:
The final project must be portfolio-quality, resume-ready, and suitable for explaining in frontend developer interviews.
